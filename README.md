# BattleBots Simulation

## Overview
BattleBots Simulation is a Java-based project that simulates autonomous robots competing in an arena. Each bot has its own behavior and logic, and the simulation focuses on object-oriented design, interaction between entities, and game-style state management.

## Features
- Arena-based robot combat simulation
- Autonomous bot behavior and decision-making
- Multiple interacting entities (bots, arena, environment)
- Visual and audio assets to enhance the simulation

## Technologies Used
- Java
- Object-Oriented Programming (OOP)

## Project Structure
- `arena/` – Arena logic and environment handling  
- `bots/` – Bot definitions and behaviors  
- `images/` – Visual assets used in the simulation  
- `sounds/` – Audio assets used in the simulation  

## What I Learned
- Designing and organizing larger Java projects
- Applying object-oriented principles across multiple components
- Managing interactions between independent classes
- Debugging and iterating on game-style logic
